---
title: "Prerequisites"
description: "What you need before you build your first agent with Voice AiLunaPro"
---

Voice AiLunaPro is hosted, so there is nothing to install. To get started you need:

- **An account** at [voice.ailunapro.com](https://voice.ailunapro.com)
- **A browser with microphone access**, to talk to your agent with a [Web Call](/getting-started/first-agent)

For real phone calls and API-triggered calls, you'll also need:

- **A telephony provider**, such as Twilio. See [Connect with Telephony](/getting-started/connect-telephony).
- **An API key**, generated in the developer portal. See [Trigger Calls using API](/getting-started/trigger-calls-from-your-backend).
