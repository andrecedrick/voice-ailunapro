## API Trigger returns `400: Telephony provider not configured for this organization`

Enable **Set as default for outbound calls** on your telephony configuration. See [Connect with Telephony](/getting-started/connect-telephony).

## A message plays before my agent answers

On a Twilio trial account, Twilio plays a default message before connecting to your agent. Press any key to skip it.

## The agent never calls my tool or uses my document

A tool or Knowledge Base document only becomes available once it's attached to the node that needs it. See [Use External Tools, Knowledge](/getting-started/add-tools-and-knowledge-base).
